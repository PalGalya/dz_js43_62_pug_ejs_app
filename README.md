# Інтеграція шаблонізаторів PUG та EJS у Express сервер

Цей проект демонструє інтеграцію двох шаблонізаторів (PUG та EJS) в одному Express додатку згідно з технічним завданням:

- **PUG** використовується для сторінок користувачів (/users та /users/:userId)
- **EJS** використовується для сторінок статей (/articles та /articles/:articleId)

## Структура проекту

```
├── app.js                 # Основний файл додатку з налаштуванням шаблонізаторів
├── package.json           # Залежності: express, pug, ejs
├── bin/www                # Точка входу сервера
├── public/
│   ├── stylesheets/style.css    # CSS стилі для всіх сторінок
│   └── images/default-avatar.svg # Аватар за замовчуванням
├── routes/
│   ├── index.js           # Головна сторінка (PUG)
│   ├── users.js           # Маршрути користувачів (PUG)
│   └── articles.js        # Маршрути статей (EJS)
└── views/
    ├── pug/               # PUG шаблони
    │   ├── layout.pug     # Базовий layout для PUG
    │   ├── index.pug      # Головна сторінка
    │   ├── users.pug      # Список користувачів
    │   ├── user-detail.pug # Деталі користувача
    │   └── error.pug      # Сторінка помилки
    └── ejs/               # EJS шаблони
        ├── articles.ejs   # Список статей (повний HTML документ)
        └── article-detail.ejs # Деталі статті (повний HTML документ)
```

## Функціональність сервера

### Маршрути з PUG шаблонізатором

- **GET /** - Головна сторінка з навігацією
- **GET /users** - Список всіх користувачів з використанням PUG
- **GET /users/:userId** - Деталі конкретного користувача з використанням PUG

### Маршрути з EJS шаблонізатором

- **GET /articles** - Список всіх статей з використанням EJS
- **GET /articles/:articleId** - Повна стаття з контентом з використанням EJS

### Дані для демонстрації

- **Користувачі**: 3 тестові записи (ім'я, email, вік, біо, локація)
- **Статті**: 3 тестові записи (назва, опис, контент, автор, дата, категорія, теги)

## Встановлення та запуск

1. Встановити залежності

```bash
npm install
```

2. Запустити сервер (порт 3000 за замовчуванням)

```bash
npm start
```

3. Відкрити в браузері

```
http://localhost:3000
```

Якщо порт 3000 зайнятий:

- Git Bash / WSL

```bash
PORT=3001 npm start
```

- PowerShell

```powershell
$env:PORT=3001; npm start
```

## Налаштування шаблонізаторів

У файлі `app.js` налаштовано підтримку двох шаблонізаторів:

```javascript
// PUG як основний шаблонізатор
app.set("views", path.join(__dirname, "views"));
app.set("view engine", "pug");

// Додаткове налаштування EJS для статей
app.engine("ejs", require("ejs").renderFile);
```

### PUG (користувачі)

- Використовує базовий `layout.pug` з блоком `content`
- Мінімалістичний синтаксис без закривних тегів
- Файли: `views/pug/users.pug`, `views/pug/user-detail.pug`

### EJS (статті)

- Повноцінні HTML документи з EJS вставками
- HTML-подібний синтаксис з JavaScript вставками `<%= %>`
- Файли: `views/ejs/articles.ejs`, `views/ejs/article-detail.ejs`

## CSS стилізація

Єдиний файл стилів `/stylesheets/style.css` застосовується до всіх сторінок:

- Адаптивний дизайн з CSS Grid
- Стилі для навігації, карток та кнопок
- Респонсивний layout для мобільних пристроїв
