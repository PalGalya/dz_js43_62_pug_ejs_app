# Інтеграція шаблонізаторів PUG та EJS у Express сервер (Версія 1)

> **УВАГА**: Це архівна версія документації для базової функціональності проекту.
> Поточна версія з розширеним функціоналом знаходиться в `README.md`

Цей проект демонструє інтеграцію двох шаблонізаторів (PUG та EJS) в одному Express додатку згідно з технічним завданням:

- **PUG** використовується для сторінок користувачів (/users та /users/:userId)
- **EJS** використовується для сторінок статей (/articles та /articles/:articleId)

## Структура базового проекту

```
├── app.js                 # Основний файл додатку з налаштуванням шаблонізаторів
├── package.json           # Залежності: express, pug, ejs
├── bin/www                # Точка входу сервера
├── public/
│   ├── stylesheets/style.css    # CSS стилі для всіх сторінок
│   └── images/default-avatar.svg # Аватар за замовчуванням
├── routes/
│   ├── index.js           # Головна сторінка (PUG)
│   ├── users.js           # Маршрути користувачів (PUG)
│   └── articles.js        # Маршрути статей (EJS)
└── views/
    ├── pug/               # PUG шаблони
    │   ├── layout.pug     # Базовий layout для PUG
    │   ├── index.pug      # Головна сторінка
    │   ├── users.pug      # Список користувачів
    │   ├── user-detail.pug # Деталі користувача
    │   └── error.pug      # Сторінка помилки
    └── ejs/               # EJS шаблони
        ├── articles.ejs   # Список статей (повний HTML документ)
        └── article-detail.ejs # Деталі статті (повний HTML документ)
```

## Базова функціональність

### Маршрути з PUG шаблонізатором

- **GET /** - Головна сторінка з навігацією
- **GET /users** - Список всіх користувачів з використанням PUG
- **GET /users/:userId** - Деталі конкретного користувача з використанням PUG

### Маршрути з EJS шаблонізатором

- **GET /articles** - Список всіх статей з використанням EJS
- **GET /articles/:articleId** - Повна стаття з контентом з використанням EJS
