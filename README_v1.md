# Express сервер з PUG/EJS, статичними файлами, Cookies та JWT

Цей проект демонструє повноцінний Express додаток з:

- **Dual Template Engine**: PUG та EJS шаблонізатори в одному додатку
- **Static Files**: Favicon та статичні ресурси
- **Cookies**: Збереження налаштувань користувача (тема оформлення)
- **JWT Authentication**: Реєстрація, вхід та авторизація користувачів

## Основний функціонал

- **PUG** використовується для сторінок користувачів (/users та /users/:userId)
- **EJS** використовується для сторінок статей (/articles та /articles/:articleId)
- **Theme Switcher** - перемикач світлої/темної теми (зберігається в cookies)
- **User Authentication** - реєстрація та вхід через JWT токени

## Функціональність сервера

### Маршрути з PUG шаблонізатором

- **GET /** - Головна сторінка з навігацією
- **GET /users** - Список всіх користувачів з використанням PUG
- **GET /users/:userId** - Деталі конкретного користувача з використанням PUG

### Маршрути з EJS шаблонізатором

- **GET /articles** - Список всіх статей з використанням EJS
- **GET /articles/:articleId** - Повна стаття з контентом з використанням EJS

### Маршрути авторизації (JWT + Cookies)

- **POST /auth/register** - Реєстрація нового користувача
- **POST /auth/login** - Вхід користувача
- **POST /auth/logout** - Вихід користувача
- **GET /auth/profile** - Захищений маршрут (потрібен JWT)
- **POST /auth/theme** - Зміна теми оформлення (light/dark)

### Статичні файли

- **GET /favicon.ico** - Favicon для всіх сторінок
- **GET /stylesheets/style.css** - CSS стилі
- **GET /images/\*** - Зображення

### Дані для демонстрації

- **Користувачі**: 3 тестові записи (ім'я, email, вік, біо, локація)
- **Статті**: 3 тестові записи (назва, опис, контент, автор, дата, категорія, теги)

## Обробка помилок

Сервер включає систему обробки помилок:

- **404 Not Found** - для неіснуючих сторінок
- **500 Internal Server Error** - для серверних помилок
- **Неіснуючі користувачі/статті** - відображають відповідні повідомлення про помилку

Всі помилки обробляються через шаблон `error.pug`, який відображає:

- Код помилки
- Повідомлення про помилку
- Навігаційні посилання для повернення

## Використані технології

- **Node.js** - серверне середовище виконання
- **Express.js** - веб-фреймворк
- **PUG** - шаблонізатор для користувачів
- **EJS** - шаблонізатор для статей
- **JWT** - JSON Web Tokens для авторизації
- **bcryptjs** - хешування паролів
- **cookie-parser** - робота з cookies
- **CSS Grid** - адаптивний дизайн

## Особливості реалізації

### Cookies функціональність

- Збереження вибраної теми (light/dark) на 30 днів
- JWT токени зберігаються в httpOnly cookies для безпеки
- Збереження імені користувача для відображення в UI

### JWT авторизація

- Токени генеруються при реєстрації/вході
- Автоматична перевірка токенів для захищених маршрутів
- Безпечне зберігання в httpOnly cookies
- Термін дії токенів: 1 година

### Favicon

- Додано до всіх PUG та EJS шаблонів
- Автоматично відображається в браузері
- Розміщено в папці public/

## Встановлення та запуск

1. Встановити залежності

```bash
npm install
```

2. Запустити сервер (порт 3000 за замовчуванням)

```bash
npm start
```

3. Відкрити в браузері

```
http://localhost:3000
```

Якщо порт 3000 зайнятий:

- Git Bash / WSL

```bash
PORT=3001 npm start
```

- PowerShell

```powershell
$env:PORT=3001; npm start
```

## Налаштування шаблонізаторів

У файлі `app.js` налаштовано підтримку двох шаблонізаторів:

```javascript
// PUG як основний шаблонізатор
app.set("views", path.join(__dirname, "views"));
app.set("view engine", "pug");

// Додаткове налаштування EJS для статей
app.engine("ejs", require("ejs").renderFile);
```

### PUG (користувачі)

- Використовує базовий `layout.pug` з блоком `content`
- Мінімалістичний синтаксис без закривних тегів
- Файли: `views/pug/users.pug`, `views/pug/user-detail.pug`

### EJS (статті)

- Повноцінні HTML документи з EJS вставками
- HTML-подібний синтаксис з JavaScript вставками `<%= %>`
- Файли: `views/ejs/articles.ejs`, `views/ejs/article-detail.ejs`

## CSS стилізація

Єдиний файл стилів `/stylesheets/style.css` застосовується до всіх сторінок:

- Адаптивний дизайн з CSS Grid
- Стилі для навігації, карток та кнопок
- Респонсивний layout для мобільних пристроїв
